တကယ်တမ်းပြောရရင် Cron Job တွေ ရေးရမှာကို အသေပျင်းတာ။ သူက ရေးရတာလည်း လက်ပေါက်ကပ်သလို၊ စမ်းရတာလည်းကြာတော့ မရေးချင်ဘူးပေါ့။

ဒီကြားထဲမှာ AI tools တော်တော်များများကိုလည်း စမ်းဖြစ်တယ်။ Claude Code က သုံးလိုကောင်းပေမယ့် ကိုယ်တိုင်လိုက်ရေးနေရတုန်းပဲ။ Permission တွေပေးရတယ်။ ဘာအတွက်ကောင်းလဲဆိုတော့ အရင်ရေးထားပြီးသား Project တွေကို refactoring လုပ်တာ၊ မလိုတော့တဲ့ Code တွေဖြုတ်တာ၊ Documentation ရေးပေးတာတွေအတွက်တော့ အဆင်ပြေတယ်။ ဒါပေမယ့် Production အထိသွားဖို deployment က ကိုယ့်ဘာသာလုပ်ရတုန်းပဲ။

Google AI Studio ကျတော့ ပုံစံတစ်မျိုး။ ကိုယ်ဖြစ်ချင်တာကို ပြောလိုက်ရုံနဲ့ deployment အထိ အကုန်လုပ်ပေးသွားတယ်။ ဒါပေမယ့် ဘယ် tech stack သုံးမယ်၊ ရလာတဲ့ data ကို ဘယ်ပို့မယ်၊ personal သုံးဖို့ ဘာတွေထပ်ထည့်သင့်တယ်ဆိုတာကျ ကိုယ်တိုင်စဉ်းစားရတယ်။ သူ့ကို guideline ကောင်းကောင်းချနိုင်ရင်တော့ result က ကောင်းပါတယ်။ မဟုတ်ရင်တော့ data သိမ်းဖို့လိုရင်တောင် "မင်းရဲ့ security ပိုကောင်းဖိုအတွက် local storage သုံးထားပါတယ်" ဆိုတာမျိုးတွေ လာလုပ်တတ်သေးတယ်။ (အံမယ်၊ ဒါ ငါတို့သုံးနေကျအကွက်ပါဟ ဆိုပြီး ပြန်ငြင်းရသေးတာ 😂) Supabase လေး သုံးလိုက်ပါလားဆိုတာကိုတောင် မနည်းပြောယူရတယ်။

ဒီနေရာမှာ Clawdbot / MoltBot က ပုံစံတစ်မျိုးနဲ့ ချဉ်းကပ်လာတယ်။ သူက ကိုယ့်ရဲ့ personal assistant တစ်ယောက်နဲ့ ပိုတူတယ်။ လူတစ်ယောက်နဲ့တစ်ယောက် လိုအပ်ချက်မတူနိုင်တာကြောင့် personal assistant app တစ်ခုကို software အနေနဲ့ boundary တစ်ခုထားပြီး support ပေးလို့မရနိုင်ဘူး။

ဥပမာ၊ "မနက် ၇ နာရီဆို Tech News နဲ့ ဘောလုံးပွဲသတင်းပို့ပေး။ ကျောင်းကို ၉ နာရီသွားရမှာမို ရာသီဥတုကြည့်ပြီး ထီးယူရမလား၊ အနွေးထည်ဝတ်ရမလား ရွေးပေး။" ဆိုတဲ့ request မျိုးကို သာမန် app တစ်ခုမှာ user setting အနေနဲ့ထည့်ရင် တော်တော်ရှုပ်ထွေးသွားမှာ။

Clawdbot က ဒါကိုဖြေရှင်းပေးလိုက်တယ်။ ကျွန်တော့်အနေနဲ့ ဘာ Logic, Cron Code မှ သိစရာမလိုဘဲ၊ "မနက် ၇ နာရီတိုင်း ငါ့ကို ဘောလုံးပွဲသတင်းပို့ပေး" လို့ပြောလိုက်ရုံနဲ့ သူက သူ့ဘာသာသူ Code ရေး၊ API ခေါ်၊ ဘာသာပြန်ပြီး ဆောင်းပါးတစ်ပုဒ်အနေနဲ့ ပြန်ပို့ပေးတယ်။ ကိုယ့်ရဲ့ communication channel (Telegram, Slack) မှာ တစ်ခါတည်း လာပြပေးတဲ့ Concept က တကယ်ကို Revolutional Concept တစ်ခုလို မြင်တယ်။

အခု Clawdbot က ထွက်တာမကြာသေးပေမယ့် တစ်ပတ်လောက်အတွင်းမှာ အရမ်း hype သွားတာက အဲ့ concept ကြောင့်ပဲ။ Github မှာ open-source ပေးထားတော့ နောက်ထပ် integration တွေ အများကြီးဝင်လာဦးမှာ သေချာတယ်။ နောင်ဆိုရင် လူတစ်ယောက်နဲ့တစ်ယောက် ချိန်းဖို "မင်း AI Agent နဲ့ ငါ့ AI Agent နဲ့ ချိတ်ပြီး ချိန်းလိုက်ကြကွာ" ဆိုပြီး ဖြစ်လာနိုင်တယ်။

ဒီအပြောင်းအလဲတွေကြောင့် ကိုယ့်ရဲ့ Career နဲ့ပတ်သက်ပြီး နည်းနည်းတော့ ရင်လေးမိတယ်။ လွန်ခဲ့တဲ့ ၂ နှစ်က မိုးလင်းပေါက်ရေးခဲ့ရတဲ့ Code မျိုးကို အခု AI နဲ့ဆို မိနစ် ၂၀ လောက်နဲ့ ပြီးနေပြီ။(မှန်လားဆိုလဲ မှန်တယ် ဆရာရေ..) သူ့ကို အတိအကျပြောနိုင်၊ ငြင်းနိုင်၊ လမ်းညွှန်နိုင်ရင် AI က product ကောင်းတွေ ထုတ်ပေးနိုင်တဲ့ အခြေအနေဖြစ်လာပြီ။ "One-Man Company" တွေ ပိုပြီးအလုပ်ဖြစ်လာနိုင်တယ်။

ဒါကြောင့် ရှေ့ဆက်ရမယ့်ခေတ်မှာ Idea ကောင်းပြီး Social, Networking နဲ့ Personal Branding ကောင်းတဲ့သူတွေပဲ ရှင်သန်ကျန်ရစ်မယ့် ခေတ်ဖြစ်လာနိုင်ပါတယ်လို ထင်ပါတယ်။
